01 — The Problem

Scatter plots overlay. Structure disappears. Clusters become invisible.

When you plot MW against IC₅₀ on an X/Y axis, you get overplotting. Hundreds of compounds pile on top of each other, their structural relationships gone. You can't see that a cluster shares a scaffold. You can't see the activity cliff where one fluorine substitution drops potency by 10×.

The tools that solve this — Schrödinger Suite, Pipeline Pilot, StarDrop — require expensive licenses and local installation. Researchers in academia, early-stage biotech, or resource-constrained environments have no browser-native equivalent. Every open-source alternative stops at the scatter plot.

Traditional XY scatter: axis-bound, overplotted, structurally blind.
orbIC: topology-preserving, filterable, zero-install.

The core distinction

orbIC uses TMAP — a minimum spanning tree built on Tanimoto kNN similarity — so structurally related compounds stay adjacent regardless of their absolute property values. Clusters emerge from the data's own topology, not from the axes you choose.

02 — How It Works

Filter. Navigate. Inspect. One coherent workspace.

orbIC mirrors how a medicinal chemist actually thinks: narrow the space, find the pattern, examine the candidate.

Panel 01 — Filter
Property Filters
Range sliders for MW, LogP, PSA, pEC50. SMARTS substructure search. Name and SMILES input. Real-time graph redraw as filters move.
Panel 02 — Navigate
TMAP Chemical Space
MST layout positions compounds by structural similarity. Filtered hits, substructure matches, and scaffolds each rendered in distinct hues. Zoom, pan, click to select.
Panel 03 — Inspect
Compound Detail
2D structure render, full property table (pEC50, MW, LogP, PSA), structure-activity analysis, scaffold similarity score, and save to list.
Core Capabilities
TMAP / MST Layout

Tanimoto kNN similarity over ECFP4 fingerprints builds a minimum spanning tree where structural neighbors stay adjacent. Inspired by Chemical Space Networks (Heikamp & Bajorath, 2019, Frontiers in Chemistry).

SMARTS Substructure Search

Client-side substructure matching via OpenChemLib WebAssembly. Search by SMARTS, SMILES, name, or formula — results highlight on the graph instantly.

Import Any Dataset

Upload CSV with a SMILES column or JSON array. Three bundled open datasets ship precomputed: Demo Pharmacology Set (ChEMBL CC0), COX Inhibitor SAR Series (Mitchell et al., PNAS 1993), PXR Challenge Train Split (openADMET, 4,139 compounds).

Lead-Orbit View

Centers a parent molecule and renders all derivatives as orbiting satellites — the celestial metaphor made literal. Potency delta is encoded in orbital position relative to the parent.

On the Name

orbit + IC₅₀

IC₅₀ — the half-maximal inhibitory concentration — is the primary potency anchor in the platform. Compounds orbit their scaffolds. Potent hits act as gravitational centers. The celestial framing maps directly to how the layout works: high-similarity clusters form constellations, activity cliffs appear as gaps between them.

The dark interface isn't decorative. It's the sky the constellations need to become visible.

03 — Process

The browser crashed. Here's the diagnosis.

Loading the PXR Challenge dataset — 4,139 compounds — froze the browser with "Wait or terminate." Three compounding problems across the import pipeline, graph construction, and filter callbacks.

Diagnosis — Three Compounding Causes
Cause 01 — Synchronous OCL on the main thread
parseCsvToCompounds ran OpenChemLib 5–6× per compound inside a blocking Papa.parse callback. 4,139 compounds × 6 calls = ~25,000 blocking OCL operations with no browser repaint opportunity.
Cause 02 — O(n²) scaffold graph construction
TMap.graphData ran SSSearcher + kNN for every scaffold pair immediately after import. At 150 scaffolds: 22,350 synchronous OCL calls on the main thread.
Cause 03 — Query fingerprint recomputed per compound
processSmiles(similarityQuery) was called inside the per-compound filter callback — parsing the same SMILES 4,139 times per slider move.
Fixes Applied — v2
FixWhereWhat it does
Precomputed sidecardatasetService.tsBundled datasets ship with a .precomputed.json — scaffold, 16-element OCL fragment index, MW, LogP, PSA. Near-instant load, zero OCL at runtime.
Chunked async OCLdatasetService.ts50 rows per tick via setTimeout(0). Browser stays responsive; shows "Processing N / total" in the import dialog.
Scaffold capTMap.tsxKeeps the 150 highest-membership scaffolds. Prevents O(n²) lock-up while preserving meaningful topology.
Remove SSSearcher from TMapTMap.tsxEliminated 22,350 synchronous OCL calls per import. kNN Tanimoto edges alone produce an equivalent MST — saves 2–10 s of main-thread freeze.

04 — Design Decisions

The choices that shaped the product.

DecisionOptions ConsideredWhat I chose and why
TMAP over scatterXY scatter (MW vs IC₅₀), PCA/UMAP, heatmapTMAP MST preserves structural topology — compounds that are structurally similar stay adjacent. Scatter plots are axis-bound and overplot at scale. UMAP loses interpretability: you can't explain why two nodes are close to a non-specialist audience.
Dark obsidian UILight mode, neutral grayResearch sessions run long. Dark mode reduces visual fatigue and creates contrast for colored compound nodes. The celestial metaphor only works on a dark canvas — clusters read as constellations, not data points on a grid.
Client-side onlyPython/Flask backend, serverless functionsPharmaceutical compound libraries are proprietary. No backend means no data leaves the browser. Zero infrastructure cost, instant deploys.
Bundled open datasets with DOI citationsEmpty state, synthetic toy dataReal, cited literature data (ChEMBL CC0, Mitchell et al. PNAS 1993, openADMET) makes the demo scientifically credible from the first load. The citations signal domain literacy, not just engineering competence.
Precomputed sidecar filesCompute on import, Web WorkerMoves all heavy chemistry to build time. Runtime is pure data rendering — near-instant at 4,139 compounds. Web Worker is the cleaner long-term fix; sidecar was the right call for v2.
05 — What I Learned

What shipping a domain-specific tool actually looks like.

On browser performance

The bottleneck wasn't rendering — it was domain-specific computation. OpenChemLib operations are expensive in ways that don't appear in standard JS profiling intuition. The fix required tracing the full import pipeline: where OCL was called, how many times, and whether it could be precomputed or deferred.

On layout algorithm choice

UMAP and t-SNE produce visually compelling projections but sacrifice interpretability. A researcher can't explain why two compounds are adjacent in UMAP space. The MST layout's logic is transparent: nodes are close because their Tanimoto scores are high. That matters when results need to be defensible.

On data sourcing

Using real, cited literature data changes how the tool reads entirely. The COX Inhibitor SAR Series from Mitchell et al. (PNAS 1993) is a classic teaching dataset in medicinal chemistry. Including it with its DOI signals this is a tool for researchers — not a demo built on invented numbers.

On the privacy argument

Making the tool fully client-side wasn't just a technical convenience. Researchers at pharma companies can't upload lead candidates to a third-party server. "No data leaves the browser" is a genuine product feature — and impossible to add retroactively once a backend exists.

06 — Outcomes

Shipped. Open source. Ongoing.

orbIC is live, open-source under MIT, and actively being extended. The v2 performance overhaul makes the 4,139-compound PXR dataset load near-instantly. Next: Web Worker offloading for large custom imports, incremental TMAP updates, and an LSH index for sub-linear similarity search at 10k+ compounds.
